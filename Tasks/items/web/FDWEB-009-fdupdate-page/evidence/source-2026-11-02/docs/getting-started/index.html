FDUpdate

FDUpdate is a secure, product-neutral update platform for Windows and Linux.

  • FDUpdater is a Rust service, CLI, and embeddable contract library. It

    • verifies signed releases, stages and atomically activates updates, checks health, and rolls back safely.

  • FDUpdate Server is a self-hosted release, enrollment, rollout, and feedback

    • service built around Eclipse hawkBit. Its gateway keeps hawkBit, databases, signing keys, and administration private.

The protocol works with any compatible self-hosted endpoint; the client has no vendor-controlled dependency. update.fedrv.de currently serves the owner's internal installations. A managed public cloud service is not offered today.

Use cases

FDUpdate supports standalone background updates, applications retaining their own installer/UI, public and private repositories, scoped installation grants, staged rollout/rollback, one-time download sharing, server self-update, and COT service Telegram notifications for configured operators.

Quick start

Install the pinned Rust 1.98 toolchain, then:


git clone https://github.com/fedrnv/FDUpdate.git

cd FDUpdate

cargo build --workspace --all-targets --locked

cargo test --workspace --locked

cargo run -p fdupdater --bin FDUpdater -- --version

All supported operations use CLI commands; an IDE is optional. Start with the integration guide, application-managed guide, or self-hosting guide.

Architecture and trust

Remote metadata never grants local paths, services, or keys. Product-scoped Ed25519 signatures, compatibility, replay, rollout and rollback checks run before staging. Activation preserves the prior version with deterministic recovery. Server delivery rechecks installation identity, repository grant, scope and rollout. See architecture and security.
